# 김포한강한의원 업무 매뉴얼

기존 「데스크 매뉴얼」(hwp)과 「치료실 가이드」(hwpx)의 뼈대를 마크다운으로 옮긴 것입니다.
**지금은 틀만 있습니다.** 각 절의 ✍️ 자리를 채워 나가면 완성됩니다.

## 표시 규칙

문서 전체에서 아래 세 가지 표시를 씁니다.

| 표시 | 뜻 |
| --- | --- |
| ✍️ | **아직 안 채운 자리.** 여기에 내용을 적습니다 |
| `- [ ]` | 순서대로 따라 하는 일. 체크리스트 |
| ⚠️ | 원장님 확인·호출이 필요한 지점 |
| 💬 | 환자분께 그대로 하는 말 (멘트) |

## 이 매뉴얼을 채우는 순서

1. 기존 hwp·hwpx 문서를 열고, 해당 절의 ✍️ 자리에 옮겨 적습니다.
2. **그림·표로 되어 있던 부분**(예약보드, 탕전기 사진, 차트 화면 캡처)은
   `docs/manual/images/` 에 파일로 넣고 `![설명](./images/파일명.png)` 으로 겁니다.
3. 실제로 하는 일과 문서가 다르면 **문서가 틀린 것입니다.** 고치고 개정 이력에 한 줄 남깁니다.
4. 비밀번호·계정 정보는 **이 문서에 적지 않습니다.** 별도로 관리하고 여기에는 위치만 적습니다.

## 모두에게 해당하는 것

### 데스크 키워드 — **관심**

✍️ 기존 데스크 매뉴얼 첫 장의 「관심」 항목을 여기에 옮깁니다.

- 환자를 기억하고 성향을 파악하는 것
- 데스크를 비우지 않는 것 (비울 때는 미리 커버 요청)
- 대면·전화 소통 내용을 메신저로 전원과 공유하는 것

### 치료실 키워드 — ✍️

✍️ 치료실에도 같은 성격의 한 줄을 정해 둡니다.
(예: "바쁘더라도 성의있게 — 발침과 소독은 환자 몸에 직접 닿는 과정입니다")

### 지켜야 할 세 가지

1. **환자분 정보는 병원 밖으로 나가지 않습니다.** 대기실에서 이름 외의 정보를 부르지 않습니다.
2. **효과를 약속하지 않습니다.** 치료 효과·경과 설명은 원장님 몫입니다. (의료법 제56조)
3. **판단은 원장님이 합니다.** 직원이 진단하거나 치료 방향을 답하지 않습니다.
