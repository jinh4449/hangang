- **실제로 하는 일과 문서가 다르면 문서가 틀린 것입니다.** 고치고 개정 이력에 한 줄 남깁니다.
- **금액은 표 한 곳에서만** 관리합니다. 같은 숫자를 여러 문서에 적어 두면 한쪽만 고쳐집니다.

- 화면 그림은 `docs/manual/images/` 에 넣고 `![설명](./images/파일명.png)` 으로 겁니다.

## 모두에게 해당하는 것

### 데스크 키워드 — **관심**

**데스크 선생님은 환자분께 항상 관심을 갖고 있어야 합니다.**
환자분이 들어오셨을 때 기다리고 있다가 자리에서 일어나 반갑게 맞아 드리는 것을 시작으로,
기억하고, 성향을 파악하고, "내가 당신에게 관심이 있다"는 것을 표현해 주세요.

- 지난 차트 기록에서 아픈 부위나 다친 이야기를 읽어 두고, 내원 횟수와 빈도도 파악해 둡니다.
- **데스크를 지키는 것은 환자분과의 약속을 지키는 것입니다.** 환자분은 한의원에 들어오면서
  당연히 데스크에 사람이 있을 거라고 생각하십니다. 탕전하러 갈 때, 검사실 갈 때처럼
  자리를 비울 일이 있으면 **미리 커버를 요청**해 주세요.
- 데스크에서 이루어진 환자분과의 소통 내용(대면·전화)은 **메신저로 모든 스텝과 공유**해 주세요.

### 치료실 키워드 — **성의**

발침과 소독은 환자분 몸에 직접 닿는 과정입니다.
바쁘다고 급하게 하면 환자분이 바로 느끼십니다.
바쁘더라도 성의 있게 해야 환자분이 안심하고 치료를 이어 가십니다.

### 지켜야 할 세 가지

1. **환자분 정보는 병원 밖으로 나가지 않습니다.** 대기실에서 이름 외의 정보를 부르지 않습니다.
2. **효과를 약속하지 않습니다.** 치료 효과·경과 설명은 원장님 몫입니다. (의료법 제56조)
3. **판단은 원장님이 합니다.** 직원이 진단하거나 치료 방향을 답하지 않습니다.
