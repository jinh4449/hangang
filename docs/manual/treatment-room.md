## ① 환자 안내 및 환복

### 1.1 환자 동선

| 유형 | 동선 |
| --- | --- |
| 초진 | 원장님과 상담 후 **진료카드를 가지고** 나오십니다 |
| 재진 | 바로 치료실로 모십니다 (따로 상담을 원하시는 경우 제외) |

### 1.2 치료 부위 · 자세 확인

| 유형 | 어디서 확인하는가 |
| --- | --- |
| 초진 | 원장님 설명 + 진료카드 |
| 재진 | OK차트에 추가된 치료부위 + 간호사메모 |

### 1.3 환자분 모시기

- [ ] 환자복이 필요하면 **미리 챙겨서** 대기실로 갑니다
- [ ] 개인 짐을 챙겨서 오실 수 있게 안내합니다

💬 "○○○님 안녕하세요, 치료실로 모실게요~"

### 1.4 환복 안내

베드로 안내한 뒤 환자복을 드립니다.

| 치료 부위 | 멘트 |
| --- | --- |
| 목 · 어깨 | 💬 "지퍼가 **뒤로** 가게 갈아입어 주시고 호출버튼을 눌러주세요" |
| 앞쪽 | 💬 "지퍼가 **앞으로** 오게 갈아입어 주시고 호출버튼을 눌러주세요" |

- 옷은 옷걸이에, 짐은 베드 밑 바구니에 보관하도록 안내합니다
- 갈아입을 필요가 없으면 바로 치료 자세를 잡아 드리고 침 또는 물리치료를 시작합니다

### 1.5 차팅

- [ ] ① 대기실에서 환자 이름 우클릭 → 치료실 해당 베드번호로 이동 (베드 배정)
- [ ] ② 추가된 치료부위가 있으면 **간호사메모에 치료부위/자세를 정확히** 기입

  예) `왼목/좌측와위` · `우허리/우측와위` · `우발가락/똑바로(앙와위)` · `허리/엎드려서(복와위)`

## ② 물리치료 (15분)

### 2.1 부착

- [ ] 부착 전 **알콜분무기로 패드 소독**

💬 "물리치료 먼저 할게요~"

- 위치는 매뉴얼에 따르되, 환자분이 원하시는 곳이 있으면 그곳에 붙여 드립니다

  ✍️ **물리치료 위치 자료 첨부 필요** → `docs/manual/images/` 에 넣고 여기에 겁니다

- [ ] 강도는 **천천히 올립니다**
  💬 "찌릿찌릿한 느낌이 들면 말씀해 주세요"
- [ ] IR도 켜 드립니다
  💬 "IR은 온열효과로 혈액순환을 도와 통증 완화에 도움이 됩니다"

💬 "물리치료 15분 진행할 거예요. 불편한 것 있으시면 언제든 호출벨 눌러주세요~"

**차팅** — [ ] 치료실에서 ICT 타이머 클릭

### 2.2 제거 및 침치료 준비

- [ ] 환자 상태(피부 · 불편감) 확인
  💬 "강도 괜찮으셨어요?"
- [ ] 침치료 전 안내
  💬 "이제 침치료 하실 거예요"
- [ ] 치료에 필요한 카트와 의자를 준비해 둡니다

**대기가 있을 경우**

💬 "원장님 진료로 인해서 대기하셔야 하는데, 물리치료 한 번 더 해드릴까요? 아니면 쉬고 계시겠어요?"

**차팅**

- [ ] ① 치료실 타이머 '완료'
- [ ] ② 메시지 — `ㅇ원장님, ㅇ번 ㅇㅇㅇ님 침치료 있습니다~`
- [ ] 물리치료를 연장했으면 — `대기 오래 걸려 물리치료 한 번 더 해드렸습니다`

## ③ 침 · 부항 제거 (15분)

> 발침과 소독은 **환자 몸에 직접 닿는 과정**입니다.
> 바쁘다고 급하게 하면 환자분이 바로 느끼십니다. 바쁘더라도 성의 있게 해야
> 환자분이 안심하고 치료를 이어 가십니다.

### 3.1 침 제거

💬 "침 빼드릴게요"

- **천천히, 아프지 않게** 뺍니다
- 깊이 놓인 침은 피부를 잡고 **한 번에 하나씩** 뺍니다
- [ ] 빠뜨린 곳이 없는지 확인
  💬 "목과 허리, 머리 맞으신 것 맞으시죠~ 다른 곳 더 맞은 곳은 없으세요?"

⚠️ ✍️ 침 개수 확인 방법을 정해 여기에 적습니다 (놓은 수 = 뺀 수)

### 3.2 환부 소독

💬 "소독해 드릴게요"

- 몸을 살살 다룹니다
- 침 맞은 부위에 출혈이 있으면 **솜으로 10초간 지그시 압박**합니다

### 3.3 치료 후 안내

💬 "다 끝나셨어요~ 옷 갈아입고 나오시면 되세요~"
💬 "고생하셨어요, 일어날 때 어지러울 수 있으니 천천히 일어나세요"

### 3.4 추가 치료가 있는 경우

| 상황 | 멘트 |
| --- | --- |
| 바로 진행 | 💬 "진료실에서 추나/약침치료 진행하실 거예요~ 안내해 드릴게요" |
| 원장님 진료 중 | 💬 "추나/약침 치료 있으신데, 원장님이 진료 중이셔서 (옷 갈아입으시고) 잠시 기다리실게요" |

- [ ] 전체메시지 — `ㅇㅇㅇ님 추나 대기중입니다.`

### 3.5 차팅

- [ ] ① 치료실 타이머 '완료' ⚠️ **환자분이 나가시기 전엔 지우지 않습니다**
- [ ] ② 차트상 베드번호를 `999` 로 변경

## 5. 치료별 목적과 설명

환자분이 "이건 뭐예요?" 하고 물으실 때 답하는 한 줄입니다.
⚠️ **효과를 약속하는 말로 바꾸지 않습니다.**

| 치료 | 목적 · 효과 |
| --- | --- |
| ICT | 근육 이완 / 저주파로 심부 조직을 자극해 근육통 완화 |
| IR | 온열효과 / 혈액순환을 도와 통증 완화에 도움 |
| 습부항 | 피를 뽑아 순환을 좋게 함, 조직 염증 완화 |
| 전자뜸 | 혈자리에 열자극 |
| 약침 | 한약재 추출 성분 주사. 통증·염증 완화, 근육 영양 |
| 추나 | 단순추나 — 근막을 풀어 근육통 완화 / 복잡추나 — 교정치료 |
| 충격파 | 손상된 조직을 자극해 회복 도움 |
| 스피드 슬림 | 코어근육 강화(허리·복부) / 소화불량·설사·변비(위장·소장·대장) / 다이어트(복부운동) |
| ✍️ | ✍️ |

## 6. 안전

> 원본 「치료실 가이드」에는 없던 항목입니다. 실제로 하고 있는 대로 채워 주세요.

- **훈침(침 맞다 어지러워하실 때)** — ⚠️ 원장님 호출 → ✍️ 이후 순서
- **낙상** — 베드 오르내리실 때, 오래 누워 계셨다 일어나실 때
- **화상** — 전자뜸, IR. 감각이 둔하신 분(당뇨 등)은 더 자주 확인
- **전침** — ⚠️ 심장박동기 사용하시는 분
- **출혈 경향 · 항응고제 복용** — ⚠️ 원장님께 알립니다
- **임신 중** — ⚠️ 원장님께 먼저 알립니다
- **응급** — 의식 저하 · 호흡곤란 · 흉통 시 ⚠️ 원장님 호출, 119
  💬 "김포시 김포한강4로 110 일신프라자 202호 김포한강한의원입니다. 장기역 근처입니다."

## 9. 환자분께 하는 말, 하지 않는 말

**해도 되는 말** — 치료 과정 안내, 흔한 반응 안내(부항 자국, 하루 이틀 뻐근함), 불편한 곳을 묻는 말

**하지 않는 말**

- "이거 맞으면 낫습니다" — 효과를 약속하지 않습니다 (의료법 제56조)
- "몇 번 오시면 됩니다" — 치료 횟수는 원장님이 정하십니다
- "○○인 것 같은데요" — 진단하지 않습니다
- 다른 환자분 이야기 — 누가 왔었다는 것조차 말하지 않습니다
