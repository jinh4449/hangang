| 유형 | 기준 | 진료비 |
| --- | --- | --- |

### 2.2 초진 접수

**종이차트(문진표) 종류**

| 상황 | 문진표 |
| --- | --- |
| 기본 | 종이차트 |
| 다이어트 | 다이어트 문진표 |
| 약상담 | 예비 문진표 |

**신환 등록 순서**

- [ ] ① 신환 → ② 차트번호 '추천' → ③ 이름 → ④ 주소 → ⑤ 휴대폰번호
- [ ] ⑥ '동의' 선택 후 서명 받기
- [ ] ⑦ 공단자격조회 · 인증서 비밀번호
- [ ] ⑧ 저장
- [ ] 종이차트 수거하여 차트에 등록

⚠️ 건강보험 본인확인 — ✍️ 신분증 미지참 시 처리 방법을 적습니다

### 2.3 소개자 · 가족 등록

- 종이차트에 '지인 소개'가 체크된 경우, 부담 주지 않는 선에서 소개자 성함을 여쭙습니다
- 💬 ✍️ 여쭙는 멘트
- 가족이면 '가족관리'에서 가족구성원으로 추가
- 지인이면 '소개자선택'에서 소개자 추가

→ 이후 처리는 [9.2 소개환자 관리](#92-소개환자-관리)

### 2.4 재진 접수

- [ ] 성함 여쭙기 (동명이인은 생년월일로 재확인)
- [ ] 치료실로 안내

### 2.5 다이어트 환자 접수

**초진 흐름** — 차트 작성 → 접수실 프로그램 등록 → 1차 검사 → 상담 → (중간 검사 → 상담) → 수납·예약

**1차 검사 순서** — 혈압 → 인바디 → 환복 → 3D → 환복

| 검사 | 주의 |
| --- | --- |
| 혈압 | 수축기·이완기 + **맥박 수까지** 기록 |
| 인바디 | 금속 제거 후 측정. 겨드랑이 떨어지도록 양팔 벌림 (붙이면 근육량 오차) |
| 3D | ✍️ |
| 혈액검사 | 원장 오더 시. AST · ALT 측정 → 결과는 진료실에 전달 |

- 포스트잇에 날짜 · 혈압 · 혈액검사 수치를 적어 종이차트 앞 장에 붙임
- 인바디 검사지는 종이차트와 함께 엘자파일에 보관

**재진** — 매번 내원 시 인바디 측정

### 2.6 자동차보험 접수

- [ ] 환자에게 **보험사와 사고접수번호** 적어 달라고 요청
- [ ] 해당 보험사 콜센터에 전화 → 접수번호 전달 → **지불보증서**를 한의원 팩스로 받기
- [ ] 접수실 프로그램에서 자보 등록 → '추가' → 빨간 네모칸(필수) 입력
      - 사고날짜 / 보상담당자 이름 / 보상담당자 전화번호
- [ ] 구글 스프레드시트에 수상일 입력 → 자보 치료 횟수 계산
- [ ] 간호사메모에 치료 기간·가능 횟수 기입 — 예) `~26.03.10 / 매일`
- [ ] 자보안내문에 치료 가능 기간 기입
- [ ] 약봉투에 안내문 + 파스 1장 (파스는 **첫날만**)

💬 "귀가해서 불편한 곳 있으면 붙이세요. 붙였는데 가렵거나 따가우면 바로 제거하시고,
괜찮으시면 2시간 붙이고 계시다가 떼세요."

**치료 종료 처리**

- [ ] 보험사에서 지급보증중지 안내문 팩스 수신
- [ ] 환자 검색 → '자보/산재' → '수정' → 적용종료 날짜 입력 → 저장
- [ ] 전자차트 간호사메모에 '지급보증중지' 기입
- [ ] 종료일이 남았으면 메모 — 예) `26.04.11 종료`

**자보 QnA**

- Q. 한약은 무슨 효과인가요? → ✍️ (사고 후 긴장 완화 · 붓기 · 조직 재생 · 피로감)
- ✍️ 자주 나오는 질문을 여기에 더합니다

### 2.7 산재 · 의료급여 · 산정특례

## 4. 예약

### 4.1 원칙

- **예약시간 = 접수시간** (진료 시작 시간이 아닙니다)
  → 환자분은 이 개념을 모르시므로 **친절하게 설명하고 이해를 구합니다**
- 목표 — 기약 없이 기다리는 상황 예방 / 환자끼리 마주치는 일 최소화 / 의료진의 조급함 예방
- 정각 단위로 받습니다 (필요하면 30분 단위까지). `10시` ○ `11시 30분` ○ `10시 25분` ✕
- 한 시간에 **최대 8명**
- 당일 전화 예약도 받습니다 (예약 보드의 빈 시간)

### 4.2 진료시간 계산 기준

| 유형 | 계산 |
| --- | --- |
| 초진 · 추나 · 통원약침 | 1시간 |
| 재진 | 40분 |
| ✍️ | ✍️ |

### 4.3 예약 잡는 멘트

**왜 예약을 잡는가** — ✍️ (진료의 질 향상 / 미리 준비 / 붐빔 예방)
**초기 3회가 중요합니다.** 처음에 예약하고 오시는 인식이 생기면 이후로는 자연스러워집니다.

**초진 · 재초진**

💬 ✍️ "오늘 치료 받으신 거 내일 경과 확인해 드릴 건데…"

- ✕ 잘못된 질문 : "예약 도와드릴 건데, 언제 오시겠어요?"
  (부정적인 선택지를 고를 수 있게 묻지 않습니다)
- ○ 안 된다고 하실 때 : ✍️
- 마지막 멘트 : ✍️ (곤란해하시면 부담 주지 않고 마무리. 명함 드리며 끝)

**재진** — 지난 내원일을 미리 확인하고 잡습니다

| 상황 | 멘트 |
| --- | --- |
| 어제 오고 이어서 오신 분 | ✍️ |
| 3일 만에 오신 분 | ✍️ |
| 일주일 만에 오신 분 | ✍️ |

### 4.4 변경 · 취소 · 지각

- 당일 예약취소 : 예약플래너 → 예약환자관리 → 취소칸 체크(√) → 자동 취소
- **예약 시간보다 15분 이상 늦으면 일단 취소.** 대기환자가 있으면 그 자리로 넣어 드립니다.
  이후 오시면 상황 설명 + 대기시간 안내 (안타깝다는 뉘앙스, 최대한 앞으로 넣어 드리겠다는 느낌)

### 4.5 점심시간 대기명단

✍️ 작성 규칙을 적습니다.
(예약환자는 미리 기입하고 괄호에 '예약' 표기 / 실제 내원 시 생년월일 기입)

### 4.6 대기 관리와 상황 공유

- 대기실·치료실 상황은 **메신저로 꾸준히 공유**합니다
- 데스크에서 지휘합니다 — 예) "지금 흐름이면 11시 예약 환자 들어갈 베드가 없다.
  치료실 타이머 조금씩 줄여 달라" / "상담 2명 대기. 1명당 5분 안에 마쳐 달라"
- **대기실 환자분들 감정을 살핍니다** — 오래 기다리시는 분께 계속 말 걸기,
  경옥고·한약 드리기, 안쪽 상황 설명, 끝까지 언짢아 보이시면 수납하며 사과하고 파스 챙겨 드리기

### 4.7 연습 상황

> 새로 오신 분이 혼자 풀어 보는 문제입니다. 답을 먼저 가리고 생각해 보세요.

**상황 1** — 10시 통증 7명, 11시 통증 6명, 12시 통증 2명 예약된 상태

| 질문 | 답 |
| --- | --- |
| 10:10 예약 없이 재진 내원 | 치료실로 안내 (8베드 중 한 자리 비어 있음) |
| 이어서 10:11 초진 내원 | 11시 진료 가능 안내 (정중하게) |
| 11시 부부가 예약 없이 초진 내원 | 12시 안내 (11시는 한 자리뿐이라 2명은 12시) |

**상황 2** — "예약 시간 맞춰 왔는데 왜 기다리냐, 이럴 거면 예약 왜 하냐"

💬 ✍️ 응대 멘트를 여기에 옮깁니다.

## 6. 수납

### 6.1 진료비 구성

- 구성 : **본인부담금 + 비급여**. 합산 금액을 아래로 약속합니다.

| 구분 | 초진 | 재진 |
| --- | --- | --- |
| 65세 이하 | ✍️ | ✍️ |
| 65세 이상 | ✍️ | ✍️ |

| 치료 조합 | 진료비 | 비급여 |
| --- | --- | --- |
| 초음파 약침 + 추나 | ✍️ | ✍️ |
| 약침만 (추나 ✕) | ✍️ | ✍️ |
| ✍️ | | |

> 금액은 바뀔 수 있습니다. 바꿀 때는 **이 표만** 고치고, 다른 곳에 같은 숫자를 적어 두지 않습니다.

### 6.2 결제 처리

- [ ] 접수실 프로그램에서 수납 처리
- [ ] 엑셀(일일수납장부)에도 기록
- [ ] 현금 수납 시 현금영수증 발행
      ⚠️ **현금영수증은 단말기로만** 발행합니다. 컴퓨터에서는 '아니오'(중복 발급 방지)
      - 원하시는 경우 → 환자분 번호로 발행
      - 원하지 않으시는 경우 → `010-000-1234` 로 발행
- [ ] 영수증(카드·현금)에 이름 적기

**수납 후 엑셀 기록 순서**

- [ ] ① 차팅 체크된 환자분 성함 더블클릭 후 확인 → ② 수납현황 확인 → ③ 카드/현금 완료
      → ④ (현금이면) 현금영수증 항목은 '아니오'

### 6.3 진료비를 받지 않는 경우

- 자동차보험
- 산업재해 (산재보험)
- 지방분해침 치료 — 다이어트 패키지에 금액 포함 (단, '지방분해침 + 통증치료'면 수납)

## 9. CS

### 9.1 웰컴 경옥고

'실버스틱 경옥고'를 '웰컴 경옥고'로 씁니다.

| 대상 | 언제 | 멘트 |
| --- | --- | --- |
| 소개로 오신 분 | 치료 끝나고 수납할 때 | 💬 "오늘 치료 잘 받으셨어요?" |
| 소개해 주신 분 | 함께 오셨거나 다음 내원 시 | 💬 "소개해 주셔서 감사합니다" |
| 초진 | 데스크 재량 (매번 아님) | ✍️ |

⚠️ 대기실의 다른 환자분이 소외감을 느끼지 않도록 **주변을 보고** 드립니다.

### 9.2 소개환자 관리

**왜 하는가** — 지역 사회 안에서 우리 한의원에 대한 긍정적인 인식과 경험을 나누기 위해서입니다.
소개로 오신 분은 이미 신뢰가 쌓여 있어 치료 순응도가 높고, 외부 변수에 흔들리지 않는 초진 유입이 됩니다.

**행동 기준**

- [ ] ① 초진 접수 시 유입경로가 '소개'면 스몰토킹 (소개자 성함 · 관계 · 근황)
- [ ] ② 차트 메모란 '기타'에 대화 내용 공유
      예) 유입경로 : 소개(△△△님 직장동료) / 기타 : 두통 치료받고 나아서 소개
- [ ] ③ 소개자에게 감사 문자 전송
- [ ] ④ 치료 끝난 뒤 웰컴 경옥고 드리며 마무리 인사
- [ ] ⑤ 소개자 다음 내원 시 감사 인사 + 웰컴 경옥고 (접수 시 차트에 알림창)

💬 ✍️ 각 단계 멘트를 여기에 옮깁니다.
