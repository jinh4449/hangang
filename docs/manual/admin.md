## 1. 진료비 영수증 발급

### 1.1 당일 치료

⚠️ 원장실 차팅이 끝나고 **접수실 프로그램에서 수납까지 완료한 뒤** 출력합니다.

- [ ] 이름 검색 후 선택
- [ ] ① 우측 상단 '계산서 출력'
- [ ] ② '진료비계산서' (= 영수증)
- [ ] ③ '…' 선택
- [ ] ④ 해당 날짜 선택
- [ ] '요양기관 임의활용공간' 삭제
- [ ] '저장' → '프린터출력'

### 1.2 여러 날짜

'진료비계산서'와 '진료비납입확인서'를 **함께** 출력해 드립니다.

| 서류 | 담긴 내용 |
| --- | --- |
| 진료비계산서 | 총금액 |
| 진료비납입확인서 | 날짜별 금액 |

- [ ] 진료비계산서 — 당일 발급과 같은 순서. 날짜만 **기간으로** 선택해 출력
- [ ] 진료비납입확인서 — 우측 상단에서 선택 → 시작·끝 날짜 → '저장' → '프린터출력'

### 1.3 공통

- ⚠️ 모든 영수증에 **한의원 도장**을 찍고 **봉투에 넣어** 드립니다
- 모든 영수증은 **무료** 발급입니다

### 1.4 진료비 세부내역서

⚠️ 발행 **전에** 원장에게 미리 알립니다. 원장이 검토 후 발급 오더를 줍니다.
원장이 바빠 소통이 어려우면 **발급해 드리고 내용을 공유**합니다 (선조치 후보고).

## 3. 현금영수증

⚠️ **단말기로만** 발행합니다. 차트 프로그램에서 중복 발급되지 않도록 주의합니다.

| 상황 | 처리 |
| --- | --- |
| 환자분이 원하실 때 | 환자분 번호로 발행 |
| 원하지 않으실 때 | `010-000-1234` 로 발행 |

## 4. 마감 정산

### 4.1 본인부담금 장부 (엑셀)

- [ ] **실제로 들어온 금액**을 입력
- [ ] 인쇄 후, 출력한 카드 정산 용지를 위로 해서 묶기

### 4.2 카드기 정산

- [ ] 카드정산용지 출력 : `집계` → `2` → `1` → `입력`
- [ ] 엑셀의 카드 총금액과 일치하는지 확인

### 4.3 시재 정산

- [ ] **10만 원**으로 맞춤
- [ ] 나머지 금액은 마감 결재 시 원장에게 전달

### 4.4 영수증 보관

- [ ] 카드영수증 위에 현금영수증을 놓고 묶어서 보관

---

## 5. 물품 수령

- [ ] 택배를 받은 사람이 '물품수령방'에 공유
      - **택배 사진** — 열어서 물품이 보이게 촬영
      - **물품명** — 영수증의 물품 리스트 부분을 찍거나 직접 타이핑
- [ ] 물품의 종류·개수가 영수증과 맞는지 확인
- [ ] 확인 후 **영수증은 원장실로** 전달

## 6. 재고관리

### 6.1 공통 (치료실 · 탕전실)

| 항목 | 기준 |
| --- | --- |
| 확인 빈도 | 주 1회 (월~수 중) |
| 서명 | 확인한 사람 이름을 적습니다 |
| 세는 기준 | **개봉하지 않고 남은 새것의 개수** |
| 주문 | 작성은 작성대로 하고, **시켜야 할 물품과 수량은 포스트잇에 적어 원장에게 따로 보고** |

### 6.2 담당

| 구분 | 담당 | 단위 |
| --- | --- | --- |
| 약재 · 탕전용품 | 데스크 직원이 한 주씩 번갈아 | 약재는 봉지 단위 / 탕전용품은 물품마다 따로 |
| 치료실 물품 | 치료실 직원이 한 주씩 번갈아 | 물품마다 단위까지 함께 기록 |

### 6.3 재고관리표

✍️ 재고관리표 위치(파일 또는 인쇄물)와 품목 목록을 여기에 적습니다.
