## 1. 진료비 영수증 발급

### 1.1 당일 치료에 대한 영수증

⚠️ **원장실 차팅이 끝나고, 접수실 프로그램에서 수납까지 완료한 뒤** 출력합니다.

- [ ] 이름 검색 후 선택
- [ ] ① 우측 상단 **'계산서 출력'**
- [ ] ② **'진료비계산서'** (= 영수증)
- [ ] ③ **'…'** 선택
- [ ] ④ 해당 날짜 선택

![계산서 출력 메뉴](./images/admin-receipt-menu.png)

- [ ] **'요양기관 임의활용공간' 삭제**

![요양기관 임의활용공간 삭제](./images/admin-receipt-erase.png)

- [ ] '저장' → '프린터출력'

### 1.2 여러 날짜에 대한 영수증

**'진료비계산서'와 '진료비납입확인서'를 같이** 출력해 드립니다.

| 서류 | 담긴 내용 |
| --- | --- |
| 진료비계산서 | **총금액**이 나와 있습니다 |
| 진료비납입확인서 | **날짜별 금액**이 나와 있습니다 |

- [ ] **진료비계산서** — 당일 영수증 발급과 똑같이 진행하되, **날짜만 기간으로 선택**해서 출력
- [ ] **진료비납입확인서** — 우측 상단에서 선택 → 시작·끝 날짜 선택 → '저장' → '프린터출력'

![진료비납입확인서 메뉴](./images/admin-payment-cert-menu.png)

### 1.3 공통

- ⚠️ 모든 영수증에는 **'한의원 도장'을 찍고 봉투에 넣어서** 드립니다
- 모든 영수증은 **무료 발급**입니다

### 1.4 진료비 세부내역서

- ⚠️ 세부내역서는 **발행 전에 원장에게 미리 알립니다.**
- 원장이 검토한 뒤 발급해 드리도록 다시 오더를 줍니다.
- 원장이 바빠서 소통이 불가능한 경우에는 **발급해 드리고 내용을 공유**합니다. (선조치 후보고)

## 2. 진단서 · 소견서 · 진료확인서

⚠️ **원장실에서 작성하여 원장이 직접 출력**합니다. 데스크에서 출력하지 않습니다.

| 서류 | 비용 |
| --- | --- |
| 진단서 | 20,000원 |
| 소견서 | 10,000원 |
| 진료확인서 | 1,000원 |
| 초진기록지 | 1,000원 |

> ⚠️ 원본 매뉴얼 안에서 **진료확인서 금액이 두 군데에 다르게** 적혀 있습니다.
> (영수증 발급 항목에는 3,000원, 비급여 가격표에는 1,000원)
> 위 표에는 가격표 쪽 금액을 적어 두었습니다. **어느 쪽이 맞는지 확인해서 확정해 주세요.** ✍️

## 3. 현금영수증

⚠️ **현금영수증은 단말기로만** 발행합니다.
차트 프로그램에서 중복 발급되지 않도록, 컴퓨터에서는 '아니오'를 선택합니다.

| 상황 | 처리 |
| --- | --- |
| 환자분이 원하실 때 | **환자분 번호**로 발행 |
| 원하지 않으실 때 | 단말기에서 `010-0000-1234` 누르고 금액 입력 |

## 4. 마감 정산

### 4.1 본인부담금 장부 (엑셀)

- [ ] **실제로 들어온 금액**을 입력
- [ ] 인쇄한 뒤, 출력된 카드 정산 용지를 **위로 해서 묶기**

### 4.2 카드기 정산

- [ ] 카드정산용지 출력 순서 : `집계` → `2` → `1` → `입력`
- [ ] **엑셀의 카드 총금액과 일치하는지 확인**

### 4.3 시재 정산

- [ ] **10만원**으로 맞춤
- [ ] 나머지 금액은 마감 결재 시 **원장에게 전달**

### 4.4 영수증

- [ ] **카드영수증 위에 현금영수증을 놓고** 묶어서 보관

---

## 5. 물품 수령

한의원으로 택배가 오면 **수령한 사람이 '물품수령방'에 택배 내용을 공유**합니다.

- [ ] **택배 사진** — 오픈해서 물품이 나오게 찍기
- [ ] **물품명** — 영수증에서 물품 리스트 부분만 찍어서 올려도 되고, 직접 타이핑해서 올려도 됩니다

![물품 사진 예시](./images/admin-goods-photo.png)

- [ ] 물품의 **종류나 개수가 영수증 내용과 맞는지 확인**
- [ ] 확인 후 **영수증은 원장실로** 전달

## 6. 재고관리

### 6.1 치료실 · 탕전실 공통

| 항목 | 기준 |
| --- | --- |
| 확인 빈도 | **주 1회** (주 초반, 월 ~ 수 중) |
| 서명 | 재고 확인 후 **확인한 사람 이름을 서명** |
| 세는 기준 | **개봉하지 않고 남은 새것의 개수**를 기입 |
| 주문 | 작성은 작성대로 하고, **시켜야 할 물품과 수량은 포스트잇에 적어 원장에게 따로 보고** |

![개봉 · 재고 구분 보관](./images/admin-stock-storage.png)

### 6.2 담당

| 구분 | 담당 | 단위 |
| --- | --- | --- |
| **약재 · 탕전용품** | 데스크 직원이 한 주씩 번갈아 가면서 '재고관리표' 작성 | 약재는 **봉지 단위**, 탕전용품은 **물품마다 따로 체크** |
| **치료실 물품** | 치료실 직원이 한 주씩 번갈아 가면서 '재고관리표' 작성 | **물품마다 단위까지 함께 기록** |

### 6.3 재고관리표

✍️ 재고관리표 위치(파일 또는 인쇄물)와 품목 목록을 여기에 적습니다.
