# 한약 · 탕전 매뉴얼

[매뉴얼 첫 장](./README.md) · [데스크](./desk.md) · [치료실](./treatment-room.md) · [원무·정산](./admin.md)

---

## 전체 흐름

```
원장 상담·처방
  → 데스크 안내 4가지 (기간·금액 / 침치료 예약 / 보름처방 설명 / 수령방법)
  → 수납
  → 탕전 → 포장
  → 직접수령 문자  또는  택배 발송
  → 차트 처리 (수령완료 · 발송예정일 · SMS예약전송)
  → 복용법 안내
```

---

## 1. 상담 후 데스크에서 안내할 4가지

> 순서대로 빠뜨리지 않고 안내합니다. 마지막에 **주차까지 확인하고** 마칩니다.

### 1.1 기간 + 금액

- 모든 한약은 **3달이 기본**입니다
- 한 달 결제하시는 분께는 **두 달·세 달 할인을 반드시 함께** 안내합니다

💬 "한 달 한약은 ○○인데, 두 달(세 달) 하시면 5%(10%) 할인해 드려요.
원장님은 ○달 추천하시던데 어떻게 결제해 드릴까요?"

### 1.2 침치료 예약

지속적인 경과 확인과 생활관리 티칭을 위해 정기적인 침치료를 병행하는 편이 좋습니다.

💬 "그리고 일주일에 한 번씩은 침치료 오시는 게 좋은데 무슨 요일이 좋으세요?"

**못 오신다고 하실 경우** → 한 달 뒤 내원해 경과 확인하도록 상담 예약을 잡습니다

| 질문 | 답 |
| --- | --- |
| 침 맞아야 되나요? | 💬 ✍️ |
| 침 어디에 맞아요? | 💬 ✍️ |
| 시간이 안 되는데 꼭 와야 되나요? | 💬 ✍️ |

### 1.3 보름처방 설명

약만 드리고 끝이 아니라, 계속 관심을 갖고 **처방을 매번 보완해서** 나간다는 점을 안내합니다.

💬 "이번에 받으실 약은 15일치고, 다 드실 때쯤 처방 더 보완해서 이어서 드릴 거예요."

### 1.4 수령 방법 확인

💬 "약은 이번 주 ○요일쯤 나올 것 같은데 직접 수령하러 오실 수 있으세요?"

| 답 | 처리 |
| --- | --- |
| 네 | 💬 "약 준비되는 대로 문자 드리겠습니다" → 차트에 `직수` 기록 |
| 아니요 | 주소 확인 → 💬 "택배 발송하고 문자 드리겠습니다" → 차트에 `택배` 기록 (하루 더 걸림) |

⚠️ 차트에 기록이 없으면 **원장에게 확인**합니다.

## 3. 탕전

- [ ] 탕전기 전원 켜기
- [ ] 약재 보자기 넣기
- [ ] 물 ✍️ cc 맞춰 넣기
- [ ] **대각선 순서로** 뚜껑 잠그기
- [ ] '운전' 누르기 (**120분** 확인)

✍️ 몸통부분 · 뚜껑부분 사진을 `docs/manual/images/` 에 넣고 여기에 겁니다.

---

## 4. 포장

- [ ] 탕전 완료 확인
- [ ] '압축' → 약이 탕전기에서 포장기로 넘어감
- [ ] 압력계가 **0.1기압**까지 오르면 압축 멈춤
- [ ] 포장기에서 파우칭
- [ ] 바람 빼기 — ⚠️ **놀라실 수 있으니 천천히**
- [ ] 약탕기 청소

---

## 5. 포장기 청소

- [ ] 물이 빠져나가게 **밸브를 열고** 청소
- [ ] 청소할 때마다 구석구석 — 용기는 물론 **호스에 찌꺼기가 끼지 않도록**
- [ ] 물을 받아 처음 닦아 내릴 때는 '세척' 버튼도 함께
- [ ] 마지막 탕전이 끝난 뒤 청소할 때는 **구멍청소까지** (순서는 포장기 밑에 있음)

⚠️ 솔은 **정해진 구멍으로만** 넣습니다. 안에서 호스가 찢어질 수 있습니다.

---

## 6. 직접 수령

**포장까지 완료한 뒤** 문자를 보냅니다.

- [ ] ① 치료실 프로그램에서 환자 이름 검색
- [ ] ② 'SMS메세지' 클릭
- [ ] ③ '현재 환자에게 SMS 보내기'
- [ ] ④ '직접수령안내' 더블클릭
- [ ] ⑤ 'LMS' 클릭
- [ ] ⑥ '문자 전송하기'

⚠️ 다이어트 환(이터널) 복용자는 문구를 '정성들여 달인 한약' → '다이어트 환'으로 바꾸고,
**'메시지 적용'을 누른 뒤** 'LMS'를 클릭합니다. (적용을 안 누르면 바뀐 내용이 반영되지 않습니다)

---

## 7. 택배 발송

⚠️ **오후 3시 전에** 택배기사님께 전화로 수거 요청합니다.

### 7.1 송장 인쇄 (CNPLUS)

- [ ] 바탕화면 `CNPLUS` 실행
- [ ] 예약 → '기업고객건별접수'
- [ ] 받는 분 전화번호 → 이름 → 주소(돋보기) 입력
- [ ] `F5` 저장
- [ ] 아래 '출력' 체크 확인 → OZ 출력
- [ ] 표준 A4 운송장(3단) → 프린터 → 확인

> 비밀번호를 한 달에 한 번 바꾸라는 안내가 나옵니다.
> 변경 후 ✍️ (공유 위치를 적습니다. 비밀번호 자체는 이 문서에 적지 않습니다)

### 7.2 월말 정산

- **매달 첫째 근무일**에 전달 택배 수량과 비용을 원장에게 전달합니다.
- [ ] CNPLUS → '고객실적' → '기업고객 정산현황'
- [ ] '총 수량'과 '기본운임 합계' 확인
- [ ] 원장실로 메시지

---

## 8. 발송 후 차트 처리

**한약이 한의원을 떠난 뒤**(직접 수령 완료 또는 택배 수거 요청 전화 후) 처리합니다.

- [ ] 접수실 프로그램 → 예약플래너 → 한약복용 내원콜관리 → 이름 검색
- [ ] ① 진행상태를 '수령완료'로 변경
- [ ] ② '발송예정일'을 오늘 날짜로 변경
- [ ] ③ 택배 수거 시 → '택배문자전송' 클릭 / 직접 수령 시 → 완료 옆 네모칸 직접 클릭
- [ ] ④ 'SMS예약전송' 클릭
- [ ] ⑤ '수정' 클릭
- [ ] 종이차트에 **빨간색으로 오늘 날짜** 적기

### 8.1 내원콜 관리 — 이터널 미니처방

- [ ] ① 진행상태 '수령완료'
- [ ] ② 택배문자전송 옆 **완료에 체크** (택배문자전송 버튼을 누르는 게 아닙니다)
- [ ] ③ 내원콜 왼쪽 체크 해제
- [ ] ④ 기타콜 체크
- [ ] ⑤ 날짜는 **현재일 + 3일** (예: 오늘이 11일이면 14일)
- [ ] ⑥ 'SMS 예약 전송'
- [ ] ⑦ 기타콜 날짜 옆에 완료 체크가 생겼는지 확인

- 미니처방 받고 귀가하시는 분은 **3일 뒤로 예약**을 잡습니다
- 미니처방 복용 후 정규 과정으로 이어 갈 때는 **전화 상담만으로도 처방 가능**합니다

✍️ 기타콜 문자 내용을 여기에 적습니다.

## 9. 복용법 안내

복용법 파일에 **이름과 며칠 치**를 입력해 출력합니다. (종료 시 '저장 안 함')

| 종류 | 일수 | 복용법 |
| --- | --- | --- |
| 일반한약 | 15일분 | 하루 2번 (식전·식후 관계없이 오전 1회, 저녁 1회) |
| 다이어트 한약 | 20일분 | 하루 2번 **식전** |
| 자보한약 | 10일분 | 하루 2번 (총 21일치까지 처방 가능) |
| ✍️ | | |

**Q. 자동차보험 한약은 무슨 한약인가요?**

💬 "교통사고는 살짝 부딪쳐도 몸이 많이 놀라게 됩니다. 안정시켜 주고, 어혈을 없애 주고,
근육을 풀어 주고, 붓기도 빼 주는 한약이니까 꼬박꼬박 챙겨 드시는 게 좋습니다.
식전·식후, 차갑게·뜨겁게 관계없습니다. 하루 2번 복약만 잘 해 주세요."

## 11. 한약 비용표

### 성인 기준

| 기간 | 한약 | 녹용한약 |
| --- | --- | --- |
| 15일 | ✍️ | ✍️ |
| 한 달 (30일) | ✍️ | ✍️ |
| 두 달 (60일) · 5% 할인 | ✍️ | ✍️ |
| 세 달 (90일) · 10% 할인 | ✍️ | ✍️ |

| 체중 | 할인 |
