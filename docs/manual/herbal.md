[매뉴얼 첫 장](./README.md) · [데스크](./desk.md) · [치료실](./treatment-room.md) · [원무·정산](./admin.md)

## 전체 흐름

```
원장 상담·처방
  → 데스크 안내 4가지 (기간·금액 / 침치료 예약 / 보름처방 설명 / 수령방법)
  → 수납
  → 탕전 → 포장
  → 직접수령 문자  또는  택배 발송
  → 차트 처리 (수령완료 · 발송예정일 · SMS예약전송)
```

## 1. 상담 후 데스크에서 안내할 4가지

> 순서대로 빠뜨리지 않고 안내하고, **마지막에 주차까지 확인**하고 마칩니다.

### 1.1 기간 + 금액

- **모든 한약은 3달이 기본**입니다.
- 한 달 결제하시는 환자분께는 **두 달·세 달 할인을 반드시 함께** 소개해 드립니다.

💬 "한 달 한약은 ○○인데, 두 달(세 달) 하시면 5%(10%) 할인해 드려요.
원장님은 ○달 추천하시던데 어떻게 결제해 드릴까요?"

### 1.2 침치료 예약

지속적인 경과 확인과 생활관리 티칭을 위해서는 **정기적인 침 치료를 병행**하는 게 좋습니다.
(침치료 = 한약 효과 up + 생활관리)

💬 "그리고 일주일에 한 번씩은 침치료 오시는 게 좋은데 무슨 요일이 좋으세요?"

**못 오신다고 하실 경우** → **한 달 뒤에는 내원해서 경과를 확인**하시도록 상담 예약을 잡습니다.

| 질문 | 답 |
| --- | --- |
| 침 맞아야 되나요? | 💬 "오늘 상담하신 증상에 도움되는 혈자리로 침치료 하는 거라서 맞으면 더 빨리 좋아지실 수 있어요." |
| 침 어디에 맞아요? | 💬 "보통 손발 혈자리에 놓는데, 자세한 건 원장님이 처음 침치료 하시면서 설명해 주실 거예요." |
| 시간이 안 되는데 꼭 와야 되나요? | 💬 "침은 보조적인 거니까 약 열심히 드시는 게 더 중요하긴 해요. 그래도 중간에 시간되시면 한 번씩 맞으러 오세요." |

### 1.3 보름처방 설명

**약 주고 땡이 아니라** 지속적으로 관심 갖고 **처방은 매번 보완해서** 나간다는 점을 안내합니다.
(15일치씩 나눠서 나가는 것, 원장이 직접 경과를 확인하는 것)

💬 "이번에 받으실 약은 15일치고, 다 드실 때쯤 처방 더 보완해서 이어서 드릴 거예요."

### 1.4 수령 방법 확인

약이 언제 나올지 대략적으로 안내드리고 수령 방법을 확인합니다.
(택배면 하루 더 걸리는 점도 함께 말씀드립니다)

💬 "약은 이번 주 ○요일쯤 나올 것 같은데 직접 수령하러 오실 수 있으세요?"

| 답 | 처리 |
| --- | --- |
| **네** | 💬 "그럼 약 준비되는 대로 문자 드리도록 하겠습니다." → 차트에 `직수` / `문자` / `문자 후 직수` 로 기록 |
| **아니요** | 💬 "그럼 택배로 받으실 주소 한번 확인해 주세요. 약은 준비해서 택배 발송하고 문자 드리도록 하겠습니다." → 차트에 `택배` 로 기록 |

⚠️ **차트에 기록이 없으면 원장에게 확인**합니다.

## 4. 포장기 청소

- [ ] 물이 빠져나가게 **밸브를 열고** 청소
- [ ] 청소할 때마다 구석구석 닦기 — 용기는 물론, **호스에 찌꺼기가 끼지 않도록**
- [ ] 물을 받아 처음 닦아서 내릴 때는 **'세척' 버튼도 같이**
- [ ] 마지막 탕전이 끝나고 청소할 때는 **구멍청소까지** (순서는 포장기 밑에 있습니다)

⚠️ 솔을 넣어 청소할 때는 **정해진 구멍으로만** 넣습니다. 안에서 호스가 찢어질 수 있습니다.

## 5. 한약 수령

한약은 환자분이 **직접 수령**하시거나 **택배**로 받으십니다.
데스크에서 한약을 결제하실 때 어느 쪽인지 확인해 차트에 기록해 둡니다. → [1.4](#14-수령-방법-확인)

### 5.1 직접 수령

**포장까지 완료한 뒤에** 문자를 보냅니다.

- [ ] ① 치료실 프로그램에서 환자 이름으로 검색
- [ ] ② 'SMS메세지' 클릭
- [ ] ③ '현재 환자에게 SMS 보내기' 클릭
- [ ] ④ '직접수령안내' 더블클릭
- [ ] ⑤ 'LMS' 클릭
- [ ] ⑥ '문자 전송하기' 클릭

⚠️ **다이어트 환(이터널)** 으로 드시는 분께 보낼 때는 문구에서 '정성들여 달인 한약'을 지우고
'다이어트 환'으로 내용을 바꾼 뒤 **'메시지 적용'을 누르고** 'LMS'를 클릭합니다.
다른 내용을 바꿀 때도 **'메시지 적용'을 눌러야** 바뀐 내용이 반영됩니다.

### 5.2 택배

⚠️ **오후 3시 전에** 택배기사님께 전화로 수거 요청을 합니다.

**송장 인쇄 (CNPLUS)**

- [ ] 바탕화면 `CNPLUS` 실행
- [ ] 예약 → '기업고객건별접수' 클릭
- [ ] 받는 분 전화번호 입력 → 이름 입력 → 주소(돋보기) 누르고 입력
- [ ] `F5` 저장
- [ ] 아래 '출력'에 체크된 것 확인하고 **OZ 출력**
- [ ] 표준 A4 운송장(3단) → 프린터 → 확인

> 한 달에 한 번씩 비밀번호를 바꾸라는 안내가 나옵니다.
> 바꾼 뒤 공유하는 곳 ✍️ (비밀번호 자체는 이 문서에 적지 않습니다)

## 6. 한약이 한의원을 떠난 후 할 일

직접 수령이 끝났거나, 택배 수거 요청 전화를 한 뒤에 처리합니다.

- [ ] 접수실 프로그램 → 예약플래너 → **한약복용 내원콜관리** → 이름 적고 '검색'

| 예약플래너 위치 | 한약복용 내원콜관리 탭 |
| --- | --- |
| ![예약플래너](./images/herbal-planner-icon.png) | ![내원콜관리 탭](./images/herbal-callmgmt-tab.png) |

- [ ] ① 진행상태를 **'수령완료'** 로 바꾸기

- [ ] ③ 택배 수거 시 → **'택배문자전송' 클릭** / 직접 수령 시 → **완료 옆 네모칸 직접 클릭**

- [ ] ⑤ **'수정'** 클릭
- [ ] 종이차트에 **빨간색으로 오늘 날짜** 적기

## 8. 이터널 미니처방 내원콜관리

- [ ] ① 진행상태는 **'수령완료'** 로
- [ ] ② 택배문자전송 옆에 **완료에 체크** (⚠️ 택배문자전송을 누르는 게 아닙니다)
- [ ] ③ **내원콜 왼쪽 체크 없애기**
- [ ] ④ **기타콜 체크**
- [ ] ⑤ **현재일 + 3일**로 선택 (예: 오늘이 11일이면 14일)
- [ ] ⑥ **'SMS 예약 전송'** 누르기
- [ ] ⑦ 기타콜 날짜 옆에 **완료 체크가 생겼는지 확인**

![이터널 미니처방 처리](./images/herbal-eternal-mini.png)

- 미니처방 받고 귀가하시는 분들께는 **3일 뒤로 예약**을 잡습니다.
- 미니처방 복용 이후 정규 과정으로 이어서 진행하실 때는 **전화 상담만으로도 처방이 가능**합니다.

**기타콜 문자 내용**

> ✍️ 원본 매뉴얼의 문구입니다. **우리 병원 이름과 전화번호로 바꿔서** 등록해 두고,
> 등록한 뒤 이 자리에 최종본을 적습니다.

💬 "[이름]님, 안녕하세요? 김포한강한의원입니다.
미니처방 복용은 괜찮으셨는지요? 불편 없으셨다면 이어서 정규 프로그램 진행하시는 것을 추천드립니다.
전화로도 연장 처방 가능하오니 편하게 연락 주시기 바랍니다. 감사합니다.
회신번호 031-8049-7541"

## 11. 한약 비용표

> ⚠️ 금액은 이 표에서만 관리합니다. 다른 문서에 같은 숫자를 적어 두지 않습니다.
> 바뀌면 이 표를 고치고 [개정 이력](./README.md#개정-이력)에 한 줄 남깁니다.

### 성인 기준

| 기간 | 한약 | 녹용한약 |
| --- | --- | --- |
| 15일 | 25만원 | 35만원 |
| 한 달 (30일) | 45만원 | 63만원 |
| 두 달 (60일) · 5% 할인 | 85만원 | 114만원 |
| 세 달 (90일) · 10% 할인 | 120만원 | 162만원 |

### 소아

| 체중 | 적용 |
| --- | --- |
| 35 – 50 kg | 80% |
| 25 – 35 kg | 65% |
| 25 kg 이하 | 50% |

> ⚠️ 원본에는 「80% 할인 / 65% 할인 / 50% 할인」으로 적혀 있습니다.
> 체중이 큰 쪽이 더 큰 할인을 받는 셈이 되어 앞뒤가 맞지 않으므로,
> **성인 금액의 80% · 65% · 50%를 받는 것**으로 읽었습니다.
> 실제로 어느 쪽인지 확인하고 이 표를 확정해 주세요. ✍️
