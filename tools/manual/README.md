# 매뉴얼 웹페이지 만들기

`docs/manual/` 의 마크다운을 직원분들이 폰에서 볼 수 있는 웹페이지 한 장으로 만듭니다.

**매뉴얼 주소 — https://claude.ai/code/artifact/e0d21ca0-9a26-4413-a50f-e7b03ef689e4**

## 내용을 고칠 때

1. `docs/manual/` 의 마크다운을 고칩니다.
2. `python3 tools/manual/build.py`
3. 나온 HTML 을 **위 주소에 덮어씁니다.**

주소는 그대로입니다. 직원분들이 저장해 둔 링크를 다시 보낼 일이 없습니다.
주소가 바뀌는 경우는 하나뿐입니다 — 다른 파일로 새로 게시할 때. 그러지 않으면 됩니다.

## 무엇을 하는가

- 마크다운 5개를 읽어 한 페이지로 합칩니다. 문서 사이 이동 링크와 목차는
  페이지 탐색이 대신하므로 지웁니다.
- `docs/manual/images/` 의 그림 26장을 페이지 안에 그대로 담습니다.
  링크만 걸면 저장소를 못 보는 분에게는 그림이 안 보입니다.
- 「멘트」, 「※」, 「TIP)」, 「Q. / A.」 를 알아보고 각각 다르게 보여줍니다.
  환자분께 그대로 하는 말을 눈에 띄게 하려는 것입니다.
- 매뉴얼을 마지막으로 고친 날을 아래에 찍습니다. git 기록에서 가져오므로
  손으로 적을 것이 없습니다. 직원분이 지금 보는 것이 최신인지 알 수 있습니다.

## 주의

- 제목(`##`)을 고치면 목차와 찾기 결과도 자동으로 따라옵니다. 따로 손댈 것 없습니다.
- 링크를 받은 사람은 누구나 볼 수 있습니다. 가격과 운영 방식이 들어 있으니
  직원분께 직접 전달하고, 단체 대화방에 올릴 때는 방 인원을 확인해주세요.
