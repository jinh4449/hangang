# 네이버 블로그용 글

원장 칼럼과 같은 주제를 네이버 블로그에 올리기 위해 다시 쓴 글을 둔다.
칼럼 문장을 그대로 옮기면 네이버가 유사문서로 처리하므로, 같은 사실을 다른 문장으로 쓴다.

## 글의 순서 (원장님이 정한 7단계 — 반드시 이 순서)

1. **이런 분이 계셨다** — 진료실에서 자주 만나는 경우 하나. 여러 분의 이야기를 섞어 다시 쓴 예시라고 글에 밝힌다.
2. **문제가 있는데 잘 모르고 있었다** — 대부분 대수롭지 않게 넘긴다는 점.
3. **확인해 보니 이런 증상, 이런 질환이었다** — 증상의 이름과 왜 생기는지를 쉬운 말로.
4. **놔두면 이런 문제가 생긴다, 놔두면 안 된다** — 근거 있는 수치로.
5. **그럼 어떻게 하느냐** — 논문·진료지침에서 무엇을 개선하라고 하는지.
6. **한의학적으로 접근하면 이런 방법이 있다** — 5번에서 말한 개선점을 한의학이 어떻게 돕는지.
7. **고민되면 한의학적 방법을 고려해 보라** — 김포한강한의원 진료 흐름(아래 「김포한강한의원에서는」 규칙)과 연락처로 맺는다.

**체크리스트**: 2번과 3번 사이(늦어도 4번 앞)에 「혹시 나도? 체크해 보세요」를 넣는다.
`☐` 로 시작하는 6~8줄, 읽는 사람이 「이건 내 얘기다」라고 느낄 일상의 말로 쓴다.
끝에 「○개 이상이면 한 번 확인해 보세요」처럼 스스로 상담을 떠올리게 맺는다.
진단처럼 보이지 않게 「해당하면 확인해 보시라」는 정도로만 쓴다.

## 「김포한강한의원에서는」에는 진료 방식을 구체적으로 쓴다

원장님 요청(2026-10-20): 블로그에는 저희가 이 문제를 **어떻게 진료하는지**가 들어가야 한다.
짧은 한 문단이 아니라, 진료 순서를 번호로 세워 읽는 사람이 「여기서는 이렇게 보는구나」를 알게 한다.

- 저희가 실제로 하는 진료만 쓴다(근골격 초음파 삼성 V7·RMSK, 초음파 유도 약침, 추나 건강보험 연 20회, 침·전침·부항, 체외충격파, 첩약, 자동차보험; 한방내과는 자율신경·혈관·인바디·혈압 검사 → 문진·설진·복진 → 상담).
- **「다른 한의원과 달리」「우리만」「더 낫다」 같은 비교 표현은 쓰지 않는다.** 의료광고법상 다른 의료기관과의 비교·우위 표현은 금지다.
  차이는 비교하지 않고 **우리 방식을 사실대로 구체적으로 적는 것**으로 드러낸다
  (예: 「아픈 자리를 초음파로 직접 보고 시작합니다」, 「화면을 함께 보며 설명드립니다」).
- 효과 보장, 후기, 치료 전후 비교, 비용 금액은 쓰지 않는다.

## 의료광고법 — 블로그에서 특히 조심할 것

- 1번의 사례는 **치료 경과를 쓰지 않는다**(「치료받고 좋아졌다」, 「○회 만에」 금지). 증상과 상황만 쓴다.
  실제 한 분의 이야기처럼 쓰지 말고, 섞어 다시 쓴 예시라고 밝힌다.
- 한의학 치료는 「도움이 될 수 있다」까지만. 「낫는다」, 「효과가 있다」, 「완치」 금지.
- 후기, 치료 전후 비교, 다른 병원·치료법 깎아내리기, 「최고」, 「유일」 금지.
- 논문 결과를 한의학 치료의 효과로 바꿔 말하지 않는다. 6번은 「연구가 말하는 개선점을 한의학이 이런 방식으로 돕는다」는 연결까지만.
- 수치는 칼럼에서 검증한 것만 쓴다.

## 형식

- 파일: `YYYY-MM-DD-<짧은 이름>.md`. 맨 위 안내 → 제목 → 본문 → 태그 → 올리기 전 확인.
- 제목은 「김포 + 검색어, 환자 질문?」 꼴.
- 소제목마다 짧은 문단, 표는 쓰지 않는다(블로그 편집기에서 깨진다).
- **소제목을 「~요」로 끝내지 않는다**(원장님 요청 2026-10-22). 「원인은 시상하부성 무월경」, 「그냥 두면 생기는 문제, 배란과 난임」처럼 명사로 끝나는 짧은 구로 쓰고, 질문형은 한 글에 한두 개까지. 본문 말투는 그대로 편하게.
- 사진 자리는 `[사진: 무엇을 찍으면 좋은지]` 로 3~4곳.
- 각 단계 위에 `<!-- 1. ... -->` 처럼 단계 표시를 남겨 둔다. 블로그에는 붙이지 않는다.
- 끝에 칼럼 주소, 위치(김포골드라인 장기역 3·4번 출구 도보 1분), 전화(031-8049-7541). 태그 8~10개.
