# 네이버 블로그 글 쓰는 법

칼럼과 같은 주제를 블로그용으로 다시 쓴다. 기존 파일(날짜-주제.md)의 형식을 따른다.

## 「김포한강한의원에서는」에는 진료 방식을 구체적으로 쓴다

원장님 요청(2026-10-20): 블로그에는 저희가 이 문제를 **어떻게 진료하는지**가 들어가야 한다.
짧은 한 문단이 아니라, 진료 순서를 번호로 세워 읽는 사람이 「여기서는 이렇게 보는구나」를 알게 한다.

- 저희가 실제로 하는 진료만 쓴다(근골격 초음파 삼성 V7·RMSK, 초음파 유도 약침, 추나 건강보험 연 20회, 침·전침·부항, 체외충격파, 첩약, 자동차보험; 한방내과는 자율신경·혈관·인바디·혈압 검사 → 문진·설진·복진 → 상담).
- **「다른 한의원과 달리」「우리만」「더 낫다」 같은 비교 표현은 쓰지 않는다.** 의료광고법상 다른 의료기관과의 비교·우위 표현은 금지다.
  차이는 비교하지 않고 **우리 방식을 사실대로 구체적으로 적는 것**으로 드러낸다
  (예: 「아픈 자리를 초음파로 직접 보고 시작합니다」, 「화면을 함께 보며 설명드립니다」).
- 효과 보장, 후기, 치료 전후 비교, 비용 금액은 쓰지 않는다.

## 모든 블로그 글에 반드시 들어가는 것 (원장님 요청 2026-10-20)

1. **일상에서 실천하는 관리 방법** — 번호 목록 3~5개. 주제에 맞는 구체적인 생활 수칙.
2. **자주 묻는 질문** — 「### 자주 묻는 질문」 소제목 아래 3~4개. 질문은 굵게, 답은 두세 줄.
   (횟수·기간은 「상태에 따라 다르니 첫 진료 후 안내」, 비용은 금액 없이 「받기 전에 안내」.)
3. **내과 질환(소화·피로·소아·다이어트·한약 등)은 한의학적 원인과 치료 관점을 꼭 넣는다.**
   - 「한의학에서는 이렇게 봅니다」 소제목: 증상을 몸 전체의 균형(비위·간·기혈·체질 등)에서 보는 관점,
     진찰 방법(문진·설진·복진·맥진), 같은 증상도 원인에 따라 나누어 처방을 맞춘다는 점.
   - 한의학의 강점은 **방식의 특징으로** 쓴다: 한 가지 증상을 몸 전체와 함께 보고, 체질과 상태에 맞춰
     처방을 조절하고, 경과에 따라 다시 맞춘다. 양방 치료와 함께 해도 되니 복용 약을 알려 달라는 안내로 잇는다.
   - 「양방보다 낫다」「양방으로 안 되는 것이 된다」「다른 한의원과 달리」는 쓰지 않는다(의료광고법).
   - 통증·근골격 글은 이 항목 대신 위의 「진료 방식」 단계 설명을 쓴다.
