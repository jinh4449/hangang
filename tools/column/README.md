월·수·금 칼럼 초안 예약 작업이 따르는 규격이다. 원장님이 2026-11-04 초안(`herbal-medicine-liver-test-timing`)을
검수하고 「이 규격으로 고정」하라고 해서 정리했다. 새 칼럼은 이 글과 같은 틀로 쓴다.

- 본보기 칼럼: `src/content/column/questions.ts` 의 `herbLiverTest`
- 본보기 블로그 글: `tools/column/blog/2026-11-04-herbal-liver-test.md`
- 주제: `tools/column/topics.md` (발행일 이하의 첫 `[ ]` 줄, 쓰면 `[x]`)
- 블로그 7단계: `tools/column/blog/README.md`

## 칼럼 구조 (이 순서)

1. `title` — 「검색어, 환자 질문?」 꼴, 28자 안쪽. `question` 은 검색어 그대로, `summary` 는 카드용 두 줄 요약.
2. `answer` — 결론 먼저, 두 문장 안쪽. `**`·`==` 같은 강조 표시를 쓰지 않는다.
3. `body`
   - 도입 `p` 하나(통념→사실 / 연구 수치 / 「이 글을 찾으신 분은」 중 하나)
   - `summary` 「3줄 요약」(`answer` 와 어긋나지 않게)
   - 「~인가요?」 소제목 4~7개. 한의학 주제는 「한의학에서는 …」 소제목 하나, 논문 적용 소제목(「연구에서는 어땠나요?」) 하나
   - 표는 한 글에 1~2개(두 가지 이상을 견줄 때만), 첫 칸은 항목 이름
   - `h` 「상담 오실 때 이것만 챙겨 오세요」 + `ul` 두세 줄
   - 맨 끝 `tone: "check"` 상자 하나 — 「이럴 때는 검사를 함께 권해 드립니다」, 「대부분은 해당하지 않습니다」로 맺고 필요한 검사는 안내해 드린다고 쓴다
4. `clinic` — 「김포한강한의원에서는 이렇게 봅니다」. 실제로 하는 진료만. 혈액·호르몬·영상 검사는 하지 않으므로 「받으실 곳을 안내」로 쓴다.
5. `references` — `{ cite, url }` 두 칸만, 1~2편. 검색으로 존재와 수치를 확인한 것만. 확인 내용은 PR 에만 적는다.
6. 삽화 `public/column-<이름>.svg` 한 장(800×500, 글자 없음, 2KB 안팎), `QUESTION_COLUMNS` 에 추가.

## 말투

- 안심되는 사실부터. 「즉시」「지체 없이」「응급」「위험」「심각」으로 겁주지 않고 붉은 상자(`warn`)는 쓰지 않는다.
- 금기·주의는 「처방하지 않습니다」가 아니라 「말씀해 주시면 약의 강도를 조절하고 살피며 관리해 드립니다」.
- 수치는 안심되는 쪽으로 옮기되 사실을 바꾸지 않는다(예: 「99% 이상은 해당하지 않았다」).
- 의료광고법: 효과 보장·최상급·타 기관 비교·후기·비용 금액을 쓰지 않는다. 논문 결과를 우리 치료 효과로 바꿔 말하지 않는다.
