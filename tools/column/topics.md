# 원장 칼럼 주제표

월·수·금 칼럼 초안 예약 작업(Routine)이 이 표를 위에서부터 읽는다.
**발행일이 오늘 이하이고 `[ ]` 인 첫 줄**을 쓰고, 같은 PR 에서 그 줄을 `[x]` 로 바꾼다.
표의 주제가 바닥나면 아래 「분류」와 「돌리는 규칙」에 맞춰 새로 고른다.

원장님이 주제를 바꾸고 싶으면 이 파일의 줄만 고치면 된다. 순서를 바꾸거나,
`[-]` 로 표시하면 건너뛴다.

## 돌리는 규칙

- 같은 분류는 최근 3편 안에 다시 쓰지 않는다. (비디치과는 「주제가 계속 돌고 돈다」는
  원장 지적 뒤 최근 5편과 같은 계열을 건너뛰게 했다.)
- 이진희·왕소정 원장 글이 세 번 연속 한쪽으로 몰리지 않게 한다.
- 기존 칼럼보다 한 걸음 전문적으로: 진단 기준, 검사 소견의 의미, 감별, 경과 단계,
  보험 기준처럼 「병원에서 들은 말을 이해하게 해 주는」 글. 그래도 말투는 쉽고
  겁주지 않는다(`src/content/column/index.ts` 머리 주석).
- 근거 논문은 표에 적은 것이 아니라, 쓸 때 검색으로 실제 존재와 수치를 확인한 것만 쓴다.

## 제목 짓는 법

비디치과 원장 칼럼 목록(2026-04 ~ 10, 약 110편)의 실제 제목을 보고 정리했다.
거의 모든 제목이 한 가지 공식을 따른다.

**「검색어, 환자가 묻는 질문?」** — 검색어를 맨 앞에, 쉼표 뒤에 진료실에서 듣는 질문 그대로.

| 질문 꼴 | 비디치과 실제 제목 |
|---|---|
| 정상 범위 | 크라운 씌운 치아 통증, 어디까지가 정상인가요? |
| 기간 | 임플란트 전체 기간, 보통 몇 달 걸리나요? / 사랑니 통증, 보통 며칠 가나요? |
| 비교·선택 | 동종골 vs 이종골, 무엇이 다르고 언제 쓰나요? / 임플란트 픽스처 종류, 무엇이 다르고 어떻게 고를까요? |
| 시점 | 골이식 후 임플란트, 언제 심어야 안전할까요? |
| 판단 기준 | 어금니 금 갔을 때 뽑나요? 살릴 수 있는 경우의 기준 / 사랑니 안 뽑아도 되는 경우, 이렇게 판단합니다 |
| 제도·비용 | 65세 임플란트 급여, 몇 개까지 되나요? / 치과 실비, 어디까지 보장되나요? |
| 통념 확인 | 치아교정 하지 마라, 정말 맞는 말일까요? / 블랙트라이앵글 치료, 정말 메꿔질까요? |
| 원인 | 잇몸 내려앉음 원인, 무엇이 가장 흔한가요? |
| 정리형 | 임플란트 크라운 종류, 재료·고정 방식 한 번에 정리 |

- 검색어는 환자가 치는 말 그대로(「석회성 건염」「추나 건강보험」). 제목 맨 앞에 둔다.
- 물음표로 끝낸다. 답은 제목이 아니라 첫 문단(결론)이 한다.
- 카드에서 한 줄로 보이게 28자 안쪽.
- 첫 문단 여는 법도 비디치과는 거의 셋 중 하나다. ① 흔한 통념을 꺼내고 「사실은 ~」, ② 연구 수치 한 줄,
  ③ 「이 글을 찾으신 분은 대개 둘 중 하나입니다」. 그다음 「결론부터 말씀드리면」. 우리는 결론 상자가 따로 있으니
  본문 첫 문단에서 ①~③ 중 하나로 연다.
- 한 분야를 깊게 판다. 비디치과는 임플란트 하나로 재수술·나사 풀림·흔들림·뼈 녹음·상부구조·픽스처·크라운 종류·
  골이식재·급여 나이·급여 개수·전체 기간까지 따로 썼다. 우리 대표 진료(초음파·약침·어깨·허리)도 이렇게 세분한다.
- 겁주는 「후회」「하지 마라」 꼴은 쓰지 않는다(말투 규칙).
