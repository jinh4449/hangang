# 원장 칼럼 주제표

월·수·금 칼럼 초안 예약 작업(Routine)이 이 표를 위에서부터 읽는다.
**발행일이 오늘 이하이고 `[ ]` 인 첫 줄**을 쓰고, 같은 PR 에서 그 줄을 `[x]` 로 바꾼다.
표의 주제가 바닥나면 아래 「분류」와 「돌리는 규칙」에 맞춰 새로 고른다.

원장님이 주제를 바꾸고 싶으면 이 파일의 줄만 고치면 된다. 순서를 바꾸거나,
`[-]` 로 표시하면 건너뛴다.

## 돌리는 규칙

- 같은 분류는 최근 3편 안에 다시 쓰지 않는다. (비디치과는 「주제가 계속 돌고 돈다」는
  원장 지적 뒤 최근 5편과 같은 계열을 건너뛰게 했다.)
- 이진희·왕소정 원장 글이 세 번 연속 한쪽으로 몰리지 않게 한다.
- 기존 칼럼보다 한 걸음 전문적으로: 진단 기준, 검사 소견의 의미, 감별, 경과 단계,
  보험 기준처럼 「병원에서 들은 말을 이해하게 해 주는」 글. 그래도 말투는 쉽고
  겁주지 않는다(`src/content/column/index.ts` 머리 주석).
- 근거 논문은 표에 적은 것이 아니라, 쓸 때 검색으로 실제 존재와 수치를 확인한 것만 쓴다.
