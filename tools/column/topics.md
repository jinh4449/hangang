# 원장 칼럼 주제표

월·수·금 칼럼 초안 예약 작업(Routine)이 이 표를 위에서부터 읽는다.
**발행일이 오늘 이하이고 `[ ]` 인 첫 줄**을 쓰고, 같은 PR 에서 그 줄을 `[x]` 로 바꾼다.
표의 주제가 바닥나면 아래 「분류」와 「돌리는 규칙」에 맞춰 새로 고른다.

원장님이 주제를 바꾸고 싶으면 이 파일의 줄만 고치면 된다. 순서를 바꾸거나,
`[-]` 로 표시하면 건너뛴다.

## 돌리는 규칙

- 같은 분류는 최근 3편 안에 다시 쓰지 않는다. (비디치과는 「주제가 계속 돌고 돈다」는
  원장 지적 뒤 최근 5편과 같은 계열을 건너뛰게 했다.)
- 이진희·왕소정 원장 글이 세 번 연속 한쪽으로 몰리지 않게 한다.
- 기존 칼럼보다 한 걸음 전문적으로: 진단 기준, 검사 소견의 의미, 감별, 경과 단계,
  보험 기준처럼 「병원에서 들은 말을 이해하게 해 주는」 글. 그래도 말투는 쉽고
  겁주지 않는다(`src/content/column/index.ts` 머리 주석).
- 근거 논문은 표에 적은 것이 아니라, 쓸 때 검색으로 실제 존재와 수치를 확인한 것만 쓴다.

## 제목 짓는 법

비디치과 칼럼 86편(일본어 번역본에 원래 한국어 검색어가 함께 남아 있다)의 제목은
아래 다섯 꼴이 대부분이다. 우리 제목도 이 꼴로 짓되, 카드에서 한 줄로 보이게 28자 안쪽으로 줄인다.

1. **통념 바로잡기** — 「~는 반만 맞습니다」「~가 아니라 ~입니다」
   (예: 임플란트는 평생 간다는 말은 반만 맞습니다 / 입냄새의 진짜 원인은 위가 아니라 혀와 잇몸)
2. **비교** — 「A vs B, 무엇이 다른가요」
   (예: 투명교정과 철사교정 / 지르코니아·PFM·골드 크라운)
3. **정상 범위·기간** — 「~는 며칠 가나요」「어디까지가 정상인가요」
   (예: 임플란트 수술 후 붓기는 며칠? / 교정 통증, 어디까지 정상인가요)
4. **숫자로 시작하는 답** — 연구 수치나 기준값을 제목에
   (예: 성인 3명 중 1명은 이가 시립니다 / 임플란트 식립 자체는 1~3분)
5. **결정 도와주기** — 「~할까 ~할까, 이렇게 정하세요」
   (예: 자연치아를 살릴까 임플란트를 할까 / 사랑니를 안 뽑으면 어떻게 되나요)

겁주는 「후회」 꼴은 비디치과에서도 너무 몰려 원장이 직접 줄이라고 했던 계열이라 쓰지 않는다.
